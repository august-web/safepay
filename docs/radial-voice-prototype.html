How it works

  • The wheel holds all options as tactile nodes around a circle
  • When the user speaks or types a command, the wheel spins
  • Each option is announced via text-to-speech as it passes the top
  • The wheel decelerates and lands on the matched option
  • Selection is confirmed by voice, then the next menu appears
